# ITC + 非ITC 四组引用强度一键分析工具

兼容 Python 3.9+，默认读取：

- 完整配对：`/Users/bytedance/Desktop/1015引用强度/配对关系-SBERT.csv`
- 引用内容：`/Users/bytedance/Desktop/1015引用强度/引用内容.xlsx`
- 输出目录：同目录 `ITC四组引用强度分析输出/`

## 一键运行

```bash
python3 -m pip install -r requirements.txt
python3 run_analysis.py
```

也可指定文件：

```bash
python3 run_analysis.py --pair-file "/path/配对关系-SBERT.csv" --citation-file "/path/引用内容.xlsx" --output-dir "/path/out"
```

字段别名自动识别。若字段缺失或不唯一，程序停止并在输出目录写出 `字段识别诊断.csv`，列明候选与全部实际字段。

## 四组定义

- Q11：`sbert相似度 >= 0.60` 且 `耦合强度 >= 10`
- Q10：`sbert相似度 >= 0.60` 且 `耦合强度 < 10`
- Q01：`sbert相似度 < 0.60` 且 `耦合强度 >= 10`
- Q00：两者均低于阈值

任一阈值缺失者标记为 `阈值缺失`，不进入四组推断比较，但保留在全量结果。

## 题名主键匹配（正式口径）

正式匹配的唯一主键是 **标准化题名对 `(施引文献D题名, 被引文献A题名)`**，不优先看WOSID，也不使用WOSID决定是否纳入。

1. 第一层“题名保守精确”：HTML反转义、Unicode NFKC、`casefold`、Unicode空白折叠，并统一常见横线及单双引号变体；保留其他标点。标准化键和原始题名均写入文献对输出，便于审计。
2. 第一层未命中时，第二层“题名去标点精确”：在第一层结果上移除Unicode标点和空白，再做完整键相等判断。这仍是确定性精确匹配，不是模糊相似匹配；若规范化键对应多个对象则不自动纳入。
3. 题名缺失时标记不可匹配，**绝不回退WOSID** 纳入主结果。
4. 模糊题名只写入 `模糊题名候选_仅人工复核.csv`，绝不进入强度或统计结果。
5. WOSID仅作辅助质量审计。题名匹配成功后，即使WOSID指向其他题名pair，也保留题名匹配结果，并设置 `wosid_conflict=True`、记录冲突详情，另行输出 `WOSID与题名冲突明细.csv`。
6. `ID质量检查.csv` 和 `ID题名关联诊断.csv` 仍报告ID缺失、非纯数字、长度异常、同ID多题名、同题名多ID，但这些诊断不改变题名匹配结果。

匹配方向固定为 `(施引D题名, 被引A题名)`。引用句先在唯一题名文献对层面标准化、去重并审计 reported count，再关联所有 A-D1-D2 三元组；同一题名pair可被多个三元组复用。

## 缺失与主分析口径

**配对存在但引用内容没有覆盖，不等于强度为0。** 对应 `AB/AC_strength` 保留为空，`observable=False`。主分析只纳入双侧强度均可观测的四组三元组，并单独输出各组AB、AC及双侧覆盖率。这样不会把数据缺失错误编码为零引用。

## 全量与可比样本

- `四组全量三元组.csv`：保留全部配对行及不可观测状态。
- `主分析_双侧可观测.csv`：正式主分析样本。
- `可比样本_1比1.csv`：以Q11数量为目标，分别从Q10/Q01/Q00抽取1:1控制组。
- 优先按可识别的A分组、学科、领域、年份等**基础字段**分层；不可用时采用固定随机种子 `20261015` 随机抽样。
- 明确禁止按 `I_total` 或其他结果变量匹配。若某控制组小于Q11，则全量使用并写入 `抽样审计.csv`。随机抽样不能消除混杂，此限制在报告中明确记录。

## H1–H3与统计

- H1：`I_min / I_mean / I_total`
- H2：`D_norm / S_intensity / 完全一致率 / 差<=1率`
- H3：双侧 `>=2` 比例，以及 `双侧>=2 / 仅B>=2 / 仅C>=2 / 双侧<2` 四种组合
- 描述统计；Q11分别对Q10/Q01/Q00做双侧 Mann–Whitney U；Cliff's delta。
- 二分类比例采用卡方或Fisher；输出比例差、OR及95%CI（稀疏格使用0.5校正）；H3四组合采用卡方。
- 不做置换检验。p值未作多重比较校正，应结合效应量和置信区间解释。

## 主要输出

- `ITC四组引用强度分析报告.xlsx`（多工作表报告；超过10万行的明细仅写入前10万行预览，避免Excel单Sheet的1,048,576行上限）
- `Excel内容清单`工作表记录每张表的原始行数、Excel展示行数和写入方式；完整明细始终保存在同目录对应CSV
- 全量、主分析、可比样本、文献对强度、去重引用句、reported count审计等CSV
- `ID质量检查.csv`、`ID题名关联诊断.csv`、`WOSID与题名冲突明细.csv`、`未匹配明细.csv`、字段诊断和抽样审计
- `MannWhitneyU与CliffsDelta.csv`、`比例检验与效应量.csv`、描述统计和覆盖率CSV
- `四组核心指标_可比样本.png`、`四组覆盖率.png`

## 终端进度与日志

启动后会立即显示“正在运行”，随后按“扫描文件、读取完整配对CSV、读取引用内容、字段识别、题名标准化、四组划分、文献对聚合、三元组关联、统计检验、写出Excel/CSV、生成图表、完成”报告总体进度。耗时循环在TTY终端使用 `tqdm` 子进度条；pandas向量化步骤只报告阶段与耗时心跳，不显示虚假行级百分比。

在PyCharm、输出重定向等非TTY环境，或`tqdm`不可用时，会自动退化为带时间戳的普通日志。完整日志保存到输出目录的 `运行日志.log`；异常信息会明确指出失败阶段和日志路径。终端仅显示阶段、必要心跳和最终结果，避免重复刷屏。
